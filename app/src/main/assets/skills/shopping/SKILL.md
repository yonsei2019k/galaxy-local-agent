# 상품 비교
사용자의 상품 종류·용도·예산·판매처 조건을 현재 대화에서 파악한다. 이미 정해진 조건을 반복 질문하지 않는다. 본품과 소모품·중고·렌탈·해외 옵션을 구분한다.

search_shopping과 실제 상품 페이지에서 모델명·변형·수량·가격·통화·판매처·조회 시점을 확인한다. 다나와 같은 집계 가격을 특정 판매처의 실제 결제 가격으로 바꾸지 않는다. 차단된 페이지는 접근 실패를 밝히고 실제 얻은 링크만 남긴다.

가성비는 사용자가 중요하게 여기는 성능과 실제 확인된 사양을 기준으로 비교한다. 확인되지 않은 CADR·면적·소음·필터 비용을 만들지 않는다. 가격만 있는 상품은 사양 검증과 구분한다.

조건이 일치하는 관찰 결과 중 유리한 선택을 추천하되 전체 시장 최저가·재고·쿠폰·배송 포함 총액을 증거 없이 확정하지 않는다. 구매는 사용자가 실제 화면에서 결정하며 결제나 계정 접속을 대신 수행했다고 하지 않는다.
