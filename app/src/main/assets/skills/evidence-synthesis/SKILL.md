# 여러 기록을 근거로 종합하기
문자·대화·전사문을 함께 봐야 하는 질문에 필요한 부분만 사용한다. 공개 논문 조사 지침과 구별한다. 사용자의 실제 질문과 제외 조건을 보존하고 모든 작업에 같은 분류표나 고정 절차를 강제하지 않는다.

먼저 어떤 출처의 어느 기간을 실제로 읽었는지 구분한다. 각 사실·약속·결정·기한에 반환된 출처와 위치를 연결한다. 모델이 만든 요약만 남겨 원문과의 연결을 지우지 않는다. ID·파일 해시·조각·시간 등 도구에 없는 식별자를 꾸미지 않는다. 출처가 분리되어 있으면 같은 인물·사건이라고 추측해 합치지 않는다.

자료가 길면 출처에 맞는 analyze_sms, analyze_audio_transcript, analyze_conversation_import의 결과에서 처리된 구간과 남은 구간을 확인하고 핵심 근거를 종합한다. 저장 출처는 list_analysis_sources가 반환한 범위에서 선택한다. 중간 요약은 해석이며 원문을 대체하지 않는다. 전체 건수·총액·모든 미해결 항목을 답하려면 일부 검색 결과만으로 계산하지 않는다. 날짜·숫자 계산은 실제 확인한 값에 계산 도구를 사용할 수 있다.

재개는 실제 결과의 resumeArguments에 있는 analysisId와 expectedProcessedChunks로 요청한다. 진행 버전을 추측하거나 같은 버전을 반복하지 않는다. 다른 질문·출처는 새 분석으로 시작하고, 각 분석의 처리 범위와 출처를 유지한다.

동일 출처의 중복 읽기와 겹친 전사 구간을 중복 집계하지 않는다. 같은 문구의 재전송, 서로 다른 날의 반복 요청, 다른 사람의 비슷한 발언은 별개일 수 있다. 원문 시각과 사건 시각, 과거 계획과 현재 상태, 제안과 확정을 구분한다. 최신 메시지라는 이유만으로 다른 사건의 예전 근거를 무효화하지 않는다.

상충하는 주장과 정정·취소는 양쪽 출처를 함께 남긴다. 실제 문맥에서 같은 대상의 변경인지 확인하고 판단할 수 없으면 미해결로 둔다. 중요한 결론은 가능한 원문 근거와 비교하고, 뒷받침하지 않는 인용은 빼거나 불확실한 해석으로 표현한다. 말하지 않은 감정·진단·법적 책임을 확정하지 않는다.

핵심 주장에 반환된 analysisId/evidenceId로 read_analysis_evidence를 사용해 원문을 재확인한다. 정확한 인용 일치가 그 해석의 타당성까지 증명하지는 않는다. 전체 상세 결과·출처의 보존과 화면의 짧은 답변을 구별한다. 보고서 위치·처리율·인용은 실제 반환 값만 사용한다.

최종 답변은 질문에 맞는 결론과 핵심 근거를 먼저 제시하고, 필요한 연표·담당·기한·미해결 쟁점을 정리한다. 확인된 사실, 합리적 해석, 확인할 사항을 독자가 구분할 수 있게 쓴다. 개인 기록을 공개 검색어로 보내거나 자동으로 장기 기억·외부 메시지·일정으로 만들지 않는다. 요청된 파일 생성과 후속 행동은 실제 도구 결과대로 보고한다.
