# 웹사이트 업무

1. 요청한 사이트, 대상, 기간, 완료 결과를 확인한다. 공개 자료 비교에는 조회 도구를 우선 쓰고, 실제 사이트 조작은 기존 PC 브라우저에서 진행한다.
2. 현재 페이지의 실제 제목과 버튼을 읽는다. 이동, 팝업, 로그인, 페이지 변경 뒤에는 다시 읽어 새로 관찰된 버튼을 사용한다. 같은 버튼을 무의미하게 반복하거나 화면에 없던 대상을 추측하지 않는다.
3. 소유자 인증이 필요하면 원래 작업의 보안 카드로 넘긴다. 로그인 확인 뒤 같은 작업에서 현재 화면과 대상부터 다시 확인한다. 비밀번호나 인증번호를 대화에 요청하지 않는다.
4. 신청·결제·발신처럼 외부 상태를 바꾸는 동작은 기존 승인 범위를 따른다. 결과가 불명확하면 원래 대상의 상태를 먼저 조회한다.
5. 사이트의 확인 화면에서 대상과 완료 표시를 대조한다. PDF를 요청받았다면 공식 링크와 문서의 대상·기간을 확인하고 실제 저장 결과를 알려 준다. 현재 화면과 확인할 수 있는 다음 행동을 구체적으로 전달한다.
