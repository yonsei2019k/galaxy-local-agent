description: 교육 요건, 진행 상태와 같은 과정의 이수 증빙을 확인합니다.
version: 5
runtime: ziphap-android-local
---

1. 소유자가 맡긴 과정과 기간을 확인한다. 실제 이수 조건, 마감일과 한도는 해당 사이트의 안내를 읽는다.
2. 같은 목표의 작업 장부를 읽고 현재 사이트 진도와 대조한다. 같은 과정의 옛 이수증은 이 요청의 이수 증빙과 구분한다.
3. 먼저 사이트가 어느 기기에서 수강 시간을 인정하는지 확인한다. 모바일 수강을 지원하면 휴대폰 앱 브라우저에서 이어간다. 모바일 데이터와 배터리로도 재생할 수 있다. PC에서만 인정하면 허용된 PC 백그라운드 브라우저로 같은 수강 목록을 열어 로그인 여부와 진도를 확인한다. 휴대폰 로그인만으로 PC 로그인까지 됐다고 판단하지 않는다. PC 로그인이 필요하면 집합의 휴대폰 보안 입력 카드나 사이트가 제공하는 휴대폰 승인 방법을 사용한다. 카드가 열리면 소유자의 입력을 기다린다. 로그인 후 같은 PC 브라우저에서 사이트와 진도를 다시 확인한다. 지원되는 인증 방법이 없으면 그 이유와 마지막 진도를 대화에 남긴다. 비밀번호나 로그인 쿠키를 복사하지 않는다. 진도나 재생 속도를 조작하거나 CAPTCHA를 우회하지 않는다.
4. 비밀번호와 인증번호는 소유자가 직접 입력한다. 시험 점수와 설문 제출 결과는 사이트에서 확인한다. 의견을 묻는 항목에는 확인된 소유자 평가를 사용하고 모르면 한 번 묻는다. 재응시가 필요한 경우 사이트가 허용하는 범위에서 추가 1회만 시도한다.
5. 결과를 관찰한 뒤 장부에 반영한다. done에는 이번 목표에서 실제 관찰한 실행 근거가 필요하다. 장부는 사이트의 수료 표시를 대체하지 않는다.
6. 시각 대기, 이미 재생 중인 같은 플레이어의 종료와 휴대폰 인증 대기를 구분한다. 대기 조건에 맞춰 목표를 저장한다. PC에서 재생 중이면 눈으로 확인하거나 도구에서 얻은 현재 위치와 영상 길이로 재확인할 시각을 계산해 시각 대기(needsPlayback=false)를 예약한다. 대기 뒤 같은 영상의 실제 종료를 읽는다. 영상 종료 뒤 사이트를 다시 읽고 같은 강의의 진도나 수료를 확인한 경우만 다음 미완료 강의로 이동한다.
7. 사이트의 수료 상태를 확인하고 같은 과정의 실제 이수일과 대상 기간을 대조한다.
8. 확인한 해당 이수증의 PDF 원본을 저장한다. 직접 보이는 PDF/다운로드 링크를 먼저 확인한다. 인쇄형 문서는 휴대폰 PDF 저장 창으로 안내하고 화면 사본으로 구분한다.
9. 지정된 제출처와 과정의 일치 여부를 확인해 메일 초안과 파일을 대화에 보여준다. 결제와 실제 발송은 별도 승인 후 진행한다.
