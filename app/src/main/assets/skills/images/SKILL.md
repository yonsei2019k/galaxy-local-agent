# 이미지 제작
사용자가 원하는 주제·구도·스타일·참조 이미지와 최근 교정을 보존한다. 충분히 구체적이면 추가 조건을 요구하지 말고 선택된 품질·해상도 기본값으로 진행한다.

generate_image에는 장면을 설명하는 프롬프트를 전달한다. 모델의 설명·거절·오류 문장을 이미지 프롬프트로 그대로 넣지 않는다. 임상·해부학 교육 자료는 비성적 목적과 요청한 표현 양식을 유지하고, 번역에서 중요한 부위나 부정 조건을 조용히 바꾸지 않는다.

설치된 모델·실제 계산 경로의 한계를 따른다. 선택된 PC 보조가 있으면 해당 연결의 기존 동의 범위만 사용하고, 없으면 휴대폰 경로 상태를 확인한다. 스킬이 외부 모델·프로그램을 설치하거나 권한을 늘리지는 않는다.

실제 반환된 파일·검증 상태를 확인해 생성 결과를 안내한다. 단순 생성 성공을 해부학적 정확성·사진 사실성·원본과 동일성의 검증으로 표현하지 않는다. 실패·취소·준비 상태를 완료로 바꾸지 않는다. 갤러리 저장·공유는 별도 사용자 선택을 따른다.
