# 스킬과 연동 추천
사용자의 반복 작업·명시적 불편·선택한 프로젝트에서 필요한 능력을 파악한다. 개인 대화·파일·앱 사용 기록을 공개 검색어로 보내지 않고 일반 기능명으로 조사한다.

공식 저장소와 원문 문서에서 후보의 목적·실제 도구·지원 플랫폼·유지 상태·고정 버전·라이선스·의존성을 확인한다. 인기나 사용 빈도는 공식 통계가 없으면 알 수 없다고 한다. GitHub 별 수를 실행 빈도로 바꾸지 않는다.

현재 폰 도구로 바로 가능한 워크플로, Android 포팅이 필요한 기능, 계정 인증이나 선택된 PC가 필요한 기능을 나눈다. Python·Playwright·셸·데스크톱 앱용 스킬을 복사하기만 하면 작동한다고 말하지 않는다.

추천에는 기대 효과·검증할 위험·필요 권한·로컬 대안을 짧게 적는다. 설치·업데이트는 별도의 지원된 보안 검증·서명·사용자 승인 흐름이 있을 때만 가능하다. 문서 읽기나 추천을 설치 완료로 보고하지 않는다.
