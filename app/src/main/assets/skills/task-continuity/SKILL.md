# 장기 업무 이어가기

1. 저장된 목표에서 원하는 결과, 원래 범위, 완료 기준과 마지막 근거를 읽는다. 현재 요청에 명시된 수정 사항이 있으면 반영하고, 과거 자료의 승인 범위를 넓히지 않는다.
2. 이미 확인한 단계와 마지막으로 시도한 동작을 구분한다. 상태 변경 결과가 불확실하면 원래 대상부터 다시 읽어 중복 처리를 피한다. 같은 자료에서 새 단서가 없으면 같은 범위에서 공식 상세 화면이나 다른 자료원을 확인한다.
3. 실제 대기가 필요하면 다음 확인 시점과 이유를 기록한다. 영상 종료는 관찰된 플레이어를 기준으로 기다리고, 인증은 소유자에게 맡긴다. 대기 뒤에는 현재 사이트 상태나 작업 기록을 다시 읽는다.
4. 중간 안내에는 확인한 내용, 남은 일과 다음 움직임을 적는다. 모든 완료 기준이 실제 근거로 확인되면 결과와 요청한 파일을 같은 채팅에 전달한다.
