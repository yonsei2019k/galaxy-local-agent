# 회의 준비와 후속 조치

1. 일정에서 회의 제목, 실제 시각과 시간대, 최신 변경 여부를 확인한다. 여러 일정이 같아 어느 회의인지 달라질 때 참석자나 날짜로 좁힌다.
2. 해당 회의의 승인된 자료에서 최신 안건, 이전 결정, 필요한 자료, 답이 필요한 질문을 읽는다. 준비본에는 관련 링크나 문서명을 붙인다.
3. 회의 뒤에는 확인된 결정, 미결 사항, 후속 조치를 구분한다. 담당자·기한은 자료에 근거가 있는 경우만 적고 제안은 제안이라고 표시한다.
4. 문서나 할 일 등록을 맡았다면 요청된 항목만 생성한다. 중복 등록을 피하고 실제 저장 결과를 확인한다. 날짜만 지원하는 할 일 도구로 시간 지정 알림을 만들었다고 보고하지 않는다.
