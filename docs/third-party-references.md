# 참고한 외부 프로젝트

설계 아이디어를 참고하고 코드는 이 프로젝트에 맞게 새로 작성한 항목이다. 외부 코드를 복사한 경우에는 해당 파일에 원본 저작권과 라이선스 고지를 함께 둔다.

| 기능 | 참고 프로젝트 | 라이선스 | 이 프로젝트의 위치 |
|---|---|---|---|
| 반복 행동의 단계적 대응(상기 → 방향 전환 → 중단) | [PokeClaw](https://github.com/agents-io/PokeClaw) | Apache-2.0 | `core/.../TaskHarness.kt` `StuckRecovery` |
| 단계 예산의 경고 한도와 마무리 유도 | [PokeClaw](https://github.com/agents-io/PokeClaw) | Apache-2.0 | `core/.../TaskHarness.kt` `RoundBudget` |
