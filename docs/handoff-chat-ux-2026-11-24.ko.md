## 2. 소유자 결정 (유지)

1. **피클을 참조한다.**
   - 말은 평문으로 보인다.
   - 작업은 한 줄 카드로 보이고, 결정은 버튼으로 받는다.
   - 진행 중인 큰 작업은 헤더에 한 줄로 보인다.
   - 결과는 보관함에 모인다.
   - 피클의 약점은 따라 하지 않는다: 확인 없이 범위 확대, 검증 없는 완료 보고, 근거 없는 "N명이 맡겼어요".
2. **승인과 보안 입력은 대화 안 카드로 한다.**
   - 입력이나 승인이 끝나면 같은 카드가 작업 단계 안내 카드로 바뀐다. 이전 입력칸은 다시 나오지 않는다.
   - HIGH 위험(발송·결제·삭제·탈퇴)은 대화 안 카드에 네이티브 확인을 한 번 더 거친다.
   - 카드번호는 집순이가 받지 않는다. 사이트 결제 화면을 앱 브라우저로 열어 소유자가 직접 입력한다.
3. **캐릭터는 시안 3종(곰돌이·고양이·토끼 후드)을 모두 넣고 소유자가 고른다.**
   - 고르는 범위: 색 8가지, 표정 6가지
   - 기본값: 곰돌이·버터·기본
   - 첫 대화 안내와 나의 집순이에서 바꾼다.
4. **움직임은 SVG와 CSS 애니메이션으로 한다.**
   - 영상은 첫 실행 인트로에만 쓴다. Rive·Lottie는 쓰지 않는다.
   - "애니메이션 줄이기" 설정을 따른다.
5. **음성 대화를 앞당긴다. 이미 설치된 것만 쓴다.**
   - 듣기: ML Kit GenAI 음성 인식 Advanced (이 휴대폰은 Exynos 2600이고 삼성 AICore가 설치되어 있다)
   - 말하기: 삼성 TTS `com.samsung.SMT` (한국어 팩 설치됨)
   - 정확도 우선 전사: 이미 있는 Qwen3-ASR
   - 대체: 플랫폼 기기 내 인식
   - 새 모델은 내려받지 않는다.
6. **밝은 단일 테마를 유지한다.** 검은 화면은 금지다(2026-11-19).
