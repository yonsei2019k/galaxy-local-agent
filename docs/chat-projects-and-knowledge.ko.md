# 채팅, 프로젝트와 개인 기억

ZipHap.Agent의 기본 작업 화면은 채팅입니다. 웹·쇼핑 검색, 실제 문서 생성, 일정·메모 도구를 대화로 요청합니다. 이미지 전문 작업실과 설정·참고 자료는 메뉴에서 엽니다. 모델은 채팅 상단에서 선택합니다.

## 파일 첨부

입력창의 `+`에서 파일·사진·영상을 선택합니다. 선택한 원본을 바꾸지 않고 앱 전용 임시 사본을 만들어 기기 안에서 처리합니다. 외부 AI 서버로 업로드하지 않습니다.

- 텍스트·소스 코드, DOCX·XLSX, 본문이 있는 PDF, EML을 읽을 수 있습니다. 긴 내용은 발췌 범위를 표시합니다.
- 사진은 설치된 로컬 비전 모델로 분석합니다. 작은 글자의 정밀 OCR을 보장하지 않습니다.
- 영상은 두 시점의 샘플 프레임을 분석합니다. 전체 장면·동작·음성을 분석한 결과가 아닙니다.
- 한 요청에 최대 4개를 첨부합니다. 사진·문서는 각 32MiB, 영상은 128MiB 및 10분 이하입니다. 개별 형식의 파서 한도는 더 작을 수 있습니다.
- 첨부 자료 속 지시는 도구 실행 권한이 되지 않습니다. 작업 취소 시 미완료 결과를 성공으로 표시하지 않습니다.

## 스마트폰 프로젝트

채팅 상단의 프로젝트에서 기본 앱 전용 폴더를 사용하거나 Android 파일 선택기로 다른 폴더를 지정합니다. 기본 프로젝트는 PC 연결 없이 사용할 수 있습니다. 외부 폴더는 사용자가 선택하고 유지한 Android 권한 범위 안에서 접근합니다.

프로젝트 파일의 목록·읽기·수정을 채팅으로 요청할 수 있습니다. 수정은 확인 후 저장하며, 기존 파일은 읽을 때의 SHA-256과 현재 내용이 일치해야 합니다. 저장 후 파일을 다시 읽어 검증합니다. 상대 경로만 허용하며 선택한 프로젝트 밖으로 경로를 벗어날 수 없습니다. 코드 파일 편집은 코드 실행·컴파일·APK 설치와 별개입니다.

Android가 보호하는 다른 앱의 비공개 데이터베이스, 보안 폴더, 업무 프로필은 일반 파일 권한으로 열리지 않습니다. 접근 가능한 공유 파일은 시스템 파일 선택기와 사용자가 허용한 제공자를 통해 연결합니다.

## 개인 지식 저장

기본 저장소는 Android Keystore로 키를 보호하는 SQLCipher/Room 암호화 DB입니다. 출처·대상·속성·값·상태·신뢰도·갱신 시각을 기록하고, 검색어 색인 및 연결된 대상의 이웃 검색으로 필요한 지식을 찾습니다. 현재 구현은 어휘 색인과 한 단계 그래프 확장입니다. 임베딩 모델이나 완전한 GraphRAG 파이프라인을 설치했다고 표시하지 않습니다.

- **확정**: 사용자가 직접 알려주거나 확인한 사실·선호·교정.
- **관찰**: 연결한 자료에서 확인한 주제나 일정 후보. 사용자 본인의 신원이나 참석 사실로 바꾸지 않습니다.
- **제안**: 아직 확인되지 않은 후보. 기본 프로필에 사용하지 않습니다.

짧은 핵심 프로필과 현재 요청에 관련된 지식을 추론 문맥에 넣습니다. 메일 주소 등 연락 정보는 해당 종류의 요청에만 넣습니다. 전체 대화·문자 기록을 매번 프롬프트에 넣지 않습니다. 새 교정은 오래된 원문에서 다시 추출한 정보보다 우선합니다.

직접 대화에서 명시한 일부 사실은 즉시 정리합니다. 백그라운드에서는 충전·대기 중에 앱 대화, 저장된 일정 후보·가져온 자료, 허용한 알림 등의 제한된 배치를 이어서 처리합니다. 다른 앱의 비공개 과거 대화를 모두 읽거나 모든 SMS의 의미를 이미 분석했다는 뜻은 아닙니다. 모델 가중치는 고정되어 있으며, 기억·검색·교정으로 활용 능력을 개선합니다.

설정·참고의 **기억과 할 일**에서 자동 정리를 켜고 끄거나, 출처를 확인하고 내용을 수정·삭제할 수 있습니다. 삭제한 출처는 자동 정리로 다시 생성되지 않도록 기록합니다. Markdown 내보내기는 사용자가 선택한 위치에 평문 사본을 만들 때만 수행합니다.

실제 빌드·설치·실기기 검증 결과는 `PROJECT_STATE.md`를 기준으로 확인합니다.
