# 이미지 생성·참고 편집 보완 1089

사용자가 이미지 생성·편집 화면의 반복 실패를 신고했다. 설치 1089는 빠른 로컬 모델 선택, 입력 처리 단계 표시, 명시적 일시정지, 암호화 복구 보관을 추가한다. 기존 Qwen 작업을 다른 모델로 바꾸어 이어 실행하지 않는다. 소유자 승인에 따라 원래 입력·모델·50단계·시드·런타임 바인딩·실제 1단계 계산 지점을 보존하고, 새 요청용 선택을 FLUX 4B로 바꿨다.

기존 20B 편집 재현은 첫 단계 984초, 두 번째 단계 1206초였다. 완성 이미지 검증은 아니다. 이전 시도들의 원인은 공통 오류로 덮여 있어 복원하지 못했다. 재현 도중 명시적 suspend 뒤 클라이언트가 다시 resume하는 충돌을 확인했다. 휴대폰 프로세스가 강제 종료 뒤 다시 생성된 이유는 확정하지 않았으며, 사용자가 직접 재개했다고 추정하지 않는다.

## 실행·보관 계약

- `FLUX.2-klein-4B-Q4_0`는 명시적 선택지다. 새 기본 설정과 기존 Qwen 선택을 일괄 변경하지 않으며, 이 소유자의 기기만 승인된 업데이트 절차로 빠른 모델을 선택했다. 기본 4단계, UI 4·8단계, 실행 범위 4–50단계다. 기존 모델은 12–50단계·기본 50단계를 유지한다.
- 참고 편집도 동일한 FLUX 모델 ID/SHA를 결과와 메타데이터에서 검증한다. Qwen의 기존 새 이미지/편집 모델 구분은 유지한다. CFG1의 제외 문장은 앱과 서버가 거부한다. 입력란은 지울 수 있으며 조건을 조용히 무시하지 않는다.
- 빠른 모델만 CPU 최대 4스레드, Vulkan diffusion·VAE, VRAM 예산 2.5GiB를 쓴다. 실제 장치·메모리 예산 검사와 낮은 실행 우선순위는 유지한다. 기존 Qwen 인자·네이티브 바이너리·복구 바인딩은 바꾸지 않았다.
- 모델 검사·실행 환경·모델 로딩·입력/첫 단계 준비를 별도 `stage`로 보고한다. 실패는 고정 코드와 실제 실패 단계만 보관한다. 프롬프트·네이티브 원문·파일 경로를 진단 응답/기록에 넣지 않는다.
- 사용자 중단은 `paused=true`로 보존한다. `image_resume_guard=1` 작업기의 `/resume`은 `automatic`/`explicit` 불리언만 허용하며, 일시정지 작업은 `explicit=true`가 필요하다. 자동 재개는 기존 2회 한도와 권한 검사를 유지하고 서버 잠금 안에서도 정지 상태를 확인한다. 이전 앱의 빈 본문 재개는 일시정지된 작업을 시작하지 못하므로 앱과 작업기를 함께 업데이트한다.
- 앱은 일시정지를 계산 실패로 기록하지 않는다. 0단계는 입력·설정 보관, 양수는 실제 계산 지점으로 구분한다. 원래 요청과 취소·owner·권한·정리 규칙을 유지한다.
- `보관하고 새 작업`은 암호화된 별도 파일에 복사·재읽기한 뒤 현재 표시를 지운다. 불러오기도 반대 방향으로 먼저 복사·확인한다. 부분 실패는 중복을 남길 수 있으며 유효한 원본을 잃지 않는다. 최대 4개·64KiB이고, 원래 24시간 유효기간을 연장하지 않는다. 보관·불러오기는 PC 계산을 자동 시작하지 않는다.
- 네이티브 자식의 메모리 한도는 여유가 회복되면 현재 상주량을 고려해 늘릴 수 있다. 최소 2GiB 여유·최대 6GiB·256MiB 증가 단위·30초 확인 간격을 적용한다. 실행 중 한도를 낮추거나 다른 프로그램을 종료하지 않는다.

## 검증 범위

- core947/app926=1873 JVM 통과, 실패·오류·생략0. 전체 릴리스·테스트 APK 빌드 6분18초, lint 오류0/경고145/hint1. 이미지 시험이 텍스트 라우팅을 바꾸지 않도록 테스트 전용 수정 뒤39초 재빌드했으며 production unsigned 바이트 동일성을 확인했다.
- PC140개 중139 통과, POSIX 전용1개 생략. 실제 구형 비공개 기준선의 복구 설치 변환과 임시 설치·컴파일을 포함하며, 그 검사는 모델/서버를 실행하지 않는다. 실제 소유한 작은 자식 프로세스에서 동적 메모리 한도 적용·재읽기를 별도로 확인했다.
- 실제 서버에서 일시정지된 원래 작업에 빈 본문·자동 재개·잘못된 조합/자료형4개를 거부했고 시도 수와 저장 지점이 유지됐다. 원래 Qwen 바인딩도 다시 계산해 일치했다.
- PC 공개 합성 새 이미지69.03초: 정확한 모델·1024 PNG·크기/SHA·정리 확인. 별도 공개 참고 편집 네이티브95.36초: 빨간 정사각형→파란 정사각형, 배경/배치 육안 확인. 인물 동일성 시험이 아니다.
