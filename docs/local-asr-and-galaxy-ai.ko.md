# 로컬 음성 인식과 Galaxy AI 활용 — 2026-10-30

상태: **소스 적용, core345/app104 단위 검사, 릴리스 린트·앱/기기검사 APK 빌드 통과. 새 ASR의 서명·휴대폰 설치·한국어 실측은 아직 완료되지 않았다.** 기존 Gemma 직접 ASR의 실패를 전용 ASR의 성공으로 바꾸어 기록하지 않는다. 최신 설치·기기 예약 상태는 `agent-change-log.md`가 우선한다.

## 처리 흐름

사용자가 선택한 녹음 → 16kHz/모노 변환과 15초 조각 → 전용 ASR → 암호화된 전사 자료 → 선택한 Gemma E2B/E4B의 요약·분석. ASR 엔진은 전사가 끝나거나 실패·취소되면 해제한다. 전사 자료의 문장은 도구 실행 권한이 아니다. 모델의 가중치를 휴대폰에서 학습시켰다는 의미의 고도화가 아니다.

사진은 선택한 새 Gemma와 해당 배포본의 mmproj로 분석한다. E4B는 CPU2스레드, 미디어 배치32, 사진 입력량 제한과 메모리·과열 중지 조건을 사용한다. 가중치 자체가 커 메모리가 부족한 경우에는 속도 제한만으로 해결되지 않으므로 작업을 보류한다.

## 전사 선택지

| 선택 | 역할 | 지원 파일 포함 크기 | 상태 |
| --- | --- | ---: | --- |
| Qwen3-ASR 1.7B Q8_0 + bf16 음성 인코더 | 정확도 우선 후보, 한국어 기본 | 2,806,808,928바이트 | 고정 메타데이터·전용 JNI·선택 UI 구현, 실제 기기 검사 필요 |
| Qwen3-ASR 0.6B Q8_0 + bf16 음성 인코더 | 경량 선택지 | 1,183,324,768바이트 | 같은 검증 필요 |
| 기기 내 음성 AI · ML Kit | S26 시스템 AI 활용 후보 | 시스템에서 관리 | 공개 alpha2 SDK 연동, 실행 시 기기·한국어 지원 확인 필요 |

Qwen 모델은 [공식 프로젝트](https://github.com/QwenLM/Qwen3-ASR)의 Apache2.0 모델이며, [공식 ggml-org 변환본](https://huggingface.co/ggml-org/Qwen3-ASR-1.7B-GGUF)을 사용한다. 1.7B의 공개 다국어 평가 우위는 한국어 단독·이 휴대폰에서의 최상 성능을 입증하지 않는다. Whisper 계열은 비교 기준으로 남긴다. 모델과 음성 인코더의 커밋·파일명·전체 SHA256·크기는 `AsrCatalog.kt`에 고정했고 APK에는 넣지 않는다.

한국어·영어·자동 감지는 Qwen에 제공한다. ML Kit 선택 시에는 한국어 또는 영어를 지정한다. 시스템 AI의 지원 여부와 모델 준비는 명시적인 모델 관리 동작으로 확인하며, 일반 전사 중에는 SDK 모델을 자동 다운로드하지 않는다. 사용 불가 상태를 성공으로 표시하거나 삼성 클라우드로 전환하지 않는다.

## Galaxy AI에서 사용할 수 있는 범위

삼성 기본 앱의 Galaxy AI와 외부 앱용 공개 API는 구분한다.

- **직접 통합한 후보:** [ML Kit 기기 내 음성 인식](https://developers.google.com/ml-kit/genai/speech-recognition/android). 공식 문서는 S26/Exynos2600과 한국어 Advanced 모드를 명시한다. 배포 저장소에서 파일 입력을 지원하는 `genai-speech-recognition:1.0.0-alpha2`와 `genai-common:1.0.0-beta5`를 확인해 고정했다. 실제 AICore 기능 상태가 사용 가능해야 한다. 이를 삼성 녹음 앱의 엔진을 직접 호출하는 기능이라고 부르지 않는다.
- **추가 후보:** [ML Kit 한국어 요약 API](https://developers.google.com/ml-kit/genai/summarization/android)는 짧은 요약에 사용할 수 있다. 현재 앱의 요약 엔진을 이 API로 교체한 것은 아니다. 장문·맞춤 분석은 선택한 Gemma가 맡는다.
- **삼성 앱에서 만든 결과 활용:** [Transcript Assist 안내](https://www.samsung.com/us/galaxy-ai/)는 삼성 기본 앱의 기능 범위, 네트워크·삼성 계정 조건을 따로 설명한다. 공개 문서에서 확인하지 못한 비공개 API를 앱의 지원 기능으로 등록하지 않는다. 사용자가 내보낸 전사 텍스트 파일 또는 갤러리에서 편집한 사진은 기존 파일 선택·첨부 경로로 사용할 수 있다. 삼성 앱에서 결과를 자동 수집하는 연동은 구현·검증하지 않았다.

## 검증 기준과 현재 증거

- 격리 Android ARM64 ASR 오브젝트 컴파일 통과.
- 실제 SDK 및 현재 InferenceEngine에 대한 두 신규 엔진의 Kotlin 컴파일 통과.
- 메타데이터 제거, 한국어/이모지 보존, 빈 출력, 제어 형식과 출력 경계 검사5개 통과.
- 합성 한국어3문장 기기 검사 준비: 회의 시간, 서울/부산과 표 개수, 삭제하지 말라는 부정 지시를 보존해야 한다. 실제 인식 결과가 없는 동안 정확도·속도·메모리 우위를 주장하지 않는다.
- 두 Gemma의 사진 → 전용ASR → 선택한 Gemma의 전사 내용 분석을 확인한 보고서가 있어야 구형 Gemma 삭제 검사를 통과한다. 구형 Gemma 파일은 현재 삭제 완료 상태가 아니다.
- ML Kit는 별도 AICore 프로세스를 사용한다. 앱 PSS만으로 전체 시스템 AI 메모리를 평가하지 않는다. 취소·발열·가용 메모리와 Gemma 전환도 함께 확인한다.

원시 보고서·APK·모델·합성 음성은 저장소 밖 비공개 개발 도구에 둔다. 개인 녹음이나 기존 대화를 검증 자료로 무단 사용하지 않는다.
