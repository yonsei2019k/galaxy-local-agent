# 설정 연결과 작업 과정 표시 점검

2026-10-31. 이 문서는 화면에 기능이 있다는 사실과 실제 실행 검증을 구분한다. 최종 APK·실기기 결과는 아래 검증 기록에 별도로 남긴다.

## 점검 방법

설정의 클릭 처리, 저장 위치, 실제 실행 시 읽는 코드, 화면 복귀 후 갱신, 요청 중 화면 전환·취소를 함께 확인했다. 기본값이 빈 함수인 재사용 화면은 실제 호출부가 콜백을 전달하는지 확인한 뒤 판단했다. 연결 계정이나 Android 권한이 필요한 기능은 코드 누락과 외부 준비 상태를 구분했다.

## 확인한 결함과 보완

| 항목 | 확인한 문제 | 보완 계약 |
| --- | --- | --- |
| 방별 깊게 생각 | 임시 화면 상태에만 반영되거나 방 전환 후 복원 불일치 | 해당 방의 암호화 초안에 저장하고 늦은 다른 방 콜백 거부 |
| 프로젝트의 기억 후보 설정 | 기존 방에 바뀐 정책이 반영되지 않음 | 현재 프로젝트 정책을 실행·수집 경계에서 확인하고 기존 승인 기억을 임의 이동하지 않음 |
| Google 단일 서비스 연결 | 계정 동의 중 화면 재생성 시 원래 서비스 유실 | 서비스·권한 범위에 묶인 일회성 요청 토큰으로 결과 수신 |
| 문서·Office 내보내기 | 파일 선택 중 화면 재생성 시 빈 내용 또는 다른 내용 저장 가능 | 선택 전에 불변 파일 스냅샷·SHA를 만들고 결과를 원래 요청에만 적용 |
| 자동화 설정 | 시스템 설정에서 돌아온 뒤 권한·상태 표시가 오래됨 | 화면 복귀 시 실제 상태 재조회, 분석 선행 조건과 최근 결과 표시 |
| 스킬 라이브러리 | 실제 도구 준비 상태가 목록에 전달되지 않음 | 현재 기능 상태를 전달하고 설치된 지침과 검증된 실행을 구분 |
| 확장 보안 검사 | 설명 카드만 있고 파일 검사 진입점 없음 | 선택 ZIP·분리 manifest·독립 SHA/commit으로 실제 정적 검사 수행 |
| 첨부 칩 | 클릭 처리 없음 | 첨부 정보와 명시적인 초안 작성 버튼 제공 |
| 긴 입력 오류 | 원문·전송 차단은 유지되나 오류 안내가 표시되지 않음 | 입력창 위의 독립 안내 행으로 이동 |
| 오래된 방의 작업 목록 | 가장 오래된 1,000행을 고른 뒤 최근 항목처럼 표시 | 가장 최근 1,000행을 먼저 고르고 시간순 표시 |

대화 기록·MP4 내보내기도 선택 전에 파일·검색 조건·형식·결과 수를 동결했다. MP4만256MiB, 나머지 문서20MiB 한도를 구분하며 토큰 유실·만료·중복 콜백은 대상 파일을 열기 전에 거부한다. 모델 화면은 현재 방의 모델 선택을 동기적으로 저장하며 선택 버튼에서 실행 중 엔진을 내리지 않는다. 프로젝트 편집기는 프로젝트·폴더 버전에 고정하고 늦은 읽기 결과를 다른 프로젝트에 반영하지 않는다.

파일 전체 읽기와 모델에 전달한 범위도 분리했다. 최대8000자 정상 파일 원문을 문맥에 그대로 전달하고 실제 토큰 예산을 검사한다. 원문의 일부만 전달했거나 문맥에서 빠졌다면 전체 교체를 허용하지 않는다. UI 읽기·다른 요청·이전 폴더의 읽기 근거를 재사용할 수 없다.

## 작업 과정 카드

채팅 안에서 해당 실행의 준비, 공개 가능한 계획 요약, 모델 실행, 실제 도구 시도, 승인, 결과 검증, 파일 변경 근거를 표시한다. 숨은 사고 토큰을 추출하거나 실제로 하지 않은 단계를 만들어 보여주지 않는다. 답변 생성 종료와 사용자의 목표 달성을 구분한다.

기록은 방·실행·답변 ID에 연결한다. 모델이 같은 호출 ID를 재사용해도 실제 실행은 호스트가 발급한 별도 ID로 구별한다. 파일 변경 표시는 실제 읽기·저장 후 확인한 SHA 근거를 사용한다. 파일 변경 비교 화면이 구현되지 않은 경우 가짜 비교 버튼을 제공하지 않는다.

## 제공 범위

- CPU/GPU와 4K/8K 선택은 모델 벤치마크 옵션이다. 일상 대화는 검증된 모델 정책을 사용한다.
- 백그라운드 개선은 사용자가 선택한 활동·교정 분석과 기억 후보 관리다. 모델 가중치의 지속 재학습이 아니다.
- 확장 검사는 파일의 선언·무결성·권한 등을 확인하는 읽기 전용 검사다. 임의 실행 코드나 실행형 MCP 설치 기능은 아니다.
- 앱 알림·가져온 파일은 승인된 출처만 읽는다. 다른 앱의 보호된 과거 대화 전체 접근을 뜻하지 않는다.
- PC 도움은 선택 사항이며 기본 로컬 대화를 위해 필요하지 않다. 실제 외부 계정 연결·서비스 이용 가능 여부는 별도 확인한다.

## 검증 기록

1013 통합 APK: JVM 676개(core 453, app 223), 실기기 저장·격리 59개, 업무 도구 3개, 방별 설정 1개 통과. 실모델 강제 출력 한도·같은 답변 이어쓰기·사용자 중단 후 저장 검사 1개 통과(230.169초). 초기 4구간, 이어쓰기 후 총 7구간을 같은 답변에 보존했다. 이 짧은 강제 한도 검사는 큰 문서 품질 평가를 대신하지 않는다.

1013 화면 검사 실패2개와 전체 작업 검사 충돌은 통과로 기록하지 않았다. 오류 행 배치와 실제 스크롤 위치 검사를 수정했고, 큰 시험 코루틴을 나누고 설정 변경 전 암호화 복구 기록을 추가했다.1014에서는 화면 안내의 정확 일치/부분 일치 검사 오류1개를 바로잡았으며 생산 화면의 원문·전송 차단·오류 표시를 약화하지 않았다.

최종1015는 JVM700개와 실제 설치본96개(data60/finish10/파일근거4/저장3/설정1/업무3/UI15)를 통과했다. 실제 모델→시간 조회→불변 실행 근거→최종 답변→정확한 작업 카드 연결1개도469.669초에 통과했다. 모델·문맥·네이티브 엔진은 바꾸지 않았다. 스킬 목록의 상시 주입을 없애고, 필요한 작업이 모두 검증된 경우에만 짧은 최종 작성 문맥을 사용한다. 일부 자료·미완료 작업은 기존 경로에 남고, 최종 작성 중 새 행동 요청은 실행 전에 일시 정지한다.

이 결과는 기본 작업의 연결을 입증하지만469.669초는 여전히 긴 지연이다. 일반 요청 정확도나 모든 앱 조작 성공을 뜻하지 않는다. [최종 검증 기록](settings-validation-1015.ko.md)을 확인한다.

개인 대화, 계정, 기기 주소, 비밀키, 원본 장치 로그는 이 문서와 공개 저장소에 포함하지 않는다.
