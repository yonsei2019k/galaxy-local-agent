# ZipHap.Agent 빠른 사용 안내

## 이번 기능 사용

- 메뉴 → **문자·일정 분석**에서 전체/올해 문자 분석을 시작합니다. 대화에서 “문자 다 분석해”, “올해 문자에서 일정을 찾아줘”라고 요청해도 실행됩니다. 실제 조회 범위와 건수를 표시합니다.
- 일정 후보의 제목·시작·종료를 확인하고, 원하는 캘린더와 후보를 선택한 뒤 등록합니다. 기본 종료는 시작 1시간 뒤이며 수정할 수 있습니다. 저장 후 실제 일정 ID를 확인하고 재등록 중복을 검사합니다. 저장된 후보는 삭제할 수 있습니다.
- 메뉴 → **이미지 작업실**에서 이미지 모델을 한 번 내려받습니다. 한국어 장면 설명을 입력하면 기기에서 정리한 뒤 생성합니다. S26의 512×512/4단계는 약2분이 걸렸습니다. 생성 후 **갤러리 저장**을 선택할 수 있습니다.
- 메뉴 → **대화 기록**에서 비서 자체 대화를 검색·내보내기·삭제합니다. 카카오톡 과거 대화는 해당 앱에서 내보낸 텍스트를 **자료 연결·분석**에 가져옵니다.
- 작업 기록의 VERIFIED는 확인된 결과, PREPARED는 외부 작성 화면 또는 요청 준비, FAILED/UNVERIFIED는 결과 확인이 더 필요한 상태입니다. 외부 화면을 연 것만으로 저장·발송 완료라고 표시하지 않습니다.

현재 APK는 기능 통합과 기기 검증 중입니다. 화면이나 작업 흐름은 빌드에 따라 달라질 수 있습니다. 모델 추론과 자료 처리는 기기 안에서 진행하며, 유료 API 키는 필요하지 않습니다. 모델 파일은 APK에 포함되지 않습니다.

## 시작하기

1. **모델** 화면에서 공식 배포 항목을 내려받거나 직접 파일을 가져옵니다.
2. 가져온 모델은 배포자가 제공한 SHA-256을 확인하고, **벤치마크**를 실행해 이 기기에서 동작하는지 확인합니다.
3. **선택**을 누른 뒤 **대화** 화면으로 돌아옵니다. 한 번에 하나의 모델만 메모리에 올립니다. 자동 선택은 기기에서 실측한 준비 상태를 따릅니다.
4. 대화창에 질문이나 작성 요청을 입력합니다. 이메일 초안, 간단한 텍스트·표·코드 작성은 대화로 요청할 수 있습니다. 실제 발송이나 외부 저장은 별도 확인이 필요합니다.

모델 파일이 없거나 기기에서 성공한 측정이 없으면 일반 모델 추론을 시작할 수 없습니다. 일정 확인, 메모, 일부 승인형 도구는 모델 응답과 별개로 동작할 수 있습니다.

## 자료 연결·분석

대화 화면의 메뉴에서 **자료 연결·분석**을 엽니다.

### 카카오톡 등 대화 내보내기

1. 메신저 앱에서 필요한 대화 파일을 먼저 내보냅니다.
2. **텍스트 파일 선택**을 눌러 TXT, CSV 또는 일반 텍스트를 직접 고릅니다.
3. 가져오기가 끝나면 인식한 메시지 수, 형식, 조각 수를 확인합니다. 인식 결과는 선택한 파일의 범위만 뜻합니다.
4. 목록의 **이 자료 분석**을 눌러 선택 자료를 질문하고, **삭제**를 눌러 해당 가져오기 자료와 저장 조각을 지울 수 있습니다.

앱은 카카오톡 전체 대화나 다른 앱의 비공개 파일을 자동으로 읽지 않습니다. 알림 연동도 권한을 켠 시점 이후에 OS가 제공하는 범위에 한정됩니다.

### 문자와 통화 기록

- **문자 접근 허용**을 누르면 Android 권한 요청이 나타납니다. 허용만으로 읽기가 시작되지는 않습니다. 이후 **문자 가져오기**를 눌렀을 때에만 SMS 제공자 자료를 가져옵니다. 저장 자료는 암호화된 로컬 저장소에 기록되며 이 화면은 문자 본문을 출력하지 않습니다.
- **통화 기록 접근 허용**은 별도 권한입니다. 권한을 허용한 뒤 **통화 기록 요약**을 눌러야 조회됩니다. 결과는 통화 시각 범위·유형·길이 같은 메타데이터이며 통화 녹음이나 통화 내용을 읽거나 전사하지 않습니다.

### 녹음 파일

- **오디오 파일 직접 선택**을 눌러 시스템 파일 선택기에서 분석할 파일을 고릅니다. 이 선택은 광범위한 미디어 권한 없이 가능합니다.
- 녹음 파일 메타데이터 목록이 필요하면 별도로 **오디오 접근 허용** 후 **녹음 메타데이터 조회**를 누릅니다. 이 조회만으로 음성 내용은 열지 않습니다.
- 직접 선택한 녹음은 기기에서 짧은 PCM WAV 조각으로 변환한 뒤 로컬 전사 작업에 전달됩니다. 진행 중 대화 화면 상태에 조각 번호와 시작 시각이 표시됩니다. 완료 후 “녹음 전사 요약해줘”처럼 질문할 수 있습니다.

오디오 파이프라인은 Kotlin으로 구현되어 있고 synthetic decoder 테스트 3개가 통과했습니다. 현재 기기에서 선택한 녹음의 전사까지 이어지는 검증은 아직 진행 중입니다. 취소하면 미완성 조각을 정리하도록 설계되어 있습니다.

## 기억, 메모, 할 일

**기억과 할 일** 화면에서 장기 기억을 직접 입력하고 저장할 수 있습니다. 앱은 모든 대화를 자동으로 장기 기억으로 바꾸지 않습니다. AI가 제안한 기억은 승인 전까지 사용되지 않습니다. 삭제할 기억은 화면에서 선택해 지웁니다. 메모와 리마인더를 확인하고, 지원되는 권한을 별도로 설정할 수 있습니다.

## 현재 한계

- 모든 메신저 기록, 이메일, 통화 내용, 기기 파일을 한꺼번에 읽는 기능은 없습니다.
- 문서 화면은 구현된 TXT/CSV/PDF 작업에 한정됩니다. DOCX/XLSX 일반 편집, 신뢰 가능한 OCR, 이미지·영상 생성은 제공되지 않습니다.
- 모델의 고정 가중치를 사용자 대화로 계속 재학습하지 않습니다. 지원되는 기억 기능에서 승인한 내용만 기억으로 보관할 수 있습니다.
- 단말 성능과 전력 사용은 모델·설정·기기 상태에 따라 달라집니다. 안내된 벤치마크는 특정 Galaxy S26에서 얻은 결과이며 다른 기기의 보장이 아닙니다.

## 인터넷 없이 사용하기

모델을 한 번 내려받은 뒤 기본 대화와 기기 내 자료 처리는 인터넷 없이 가능합니다. 개발 검증에서는 INTERNET 권한을 제거한 전용 APK에서 E2B 응답과 암호화 메모 저장·검색·삭제를 통과했습니다. 평상시 설치본은 모델 다운로드와 검증된 업데이트를 위해 네트워크 권한을 유지합니다.

## 자동 업데이트

현재 릴리스0.1.2는 앱이 GitHub의 서명된 패키지를 확인해1000→1002로 스스로 업데이트하는 검증을 통과했습니다. 동일 범위의 업데이트는 자동 적용하며, 새로운 권한·기능 범위가 생기면 변경 내용을 확인합니다. Android가 별도의 설치 확인을 요구하는 경우에는 앱의 설치 알림을 이용합니다. 실제 업데이트 후 인증서와 반복 작업 승인4개의 유지도 확인했습니다.
