# ZipHap.Agent 빠른 사용 안내

## 채팅과 긴 답변

왼쪽 메뉴에서 프로젝트와 대화방을 만들고 전환합니다. 방의 메뉴에서 이름 변경, 고정, 보관·복원, 다른 프로젝트로 이동, 복제, 전체 버전 내보내기, 내용 비우기와 영구 삭제를 선택합니다. 검색은 제목과 저장된 본문을 찾습니다. 보관은 삭제와 다릅니다.

기본 사용은 **한 대화창에 원하는 결과와 조건을 입력하는 것**입니다. 입력 전에 계획·목표·스킬로 작업을 분류하지 않습니다. 필요한 자료 확인·계획·지침 읽기·실행·검증을 같은 대화에서 이어가도록 요청할 수 있습니다. 계획만 원하거나 저장하지 않기를 원하면 그 제한도 함께 적습니다. 후속 메시지로 조건을 바꾸거나 진행 중인 작업에 추가 지시를 보낼 수 있습니다.

각 방의 입력 초안·모델·첨부·읽던 메시지와 블록 위치를 복원합니다. 긴 기록은 최근 60개부터 표시하고 **이전 대화 더 보기**로 앞부분을 불러옵니다. 프로젝트 설정에서 지침·기본 모델·사용 도구·개인 기억 공유 범위를 정하고 폴더를 연결합니다. 폴더 선택기는 해당 프로젝트에 연결되며 작성 중인 설정을 유지합니다.

답변은 필요하면 여러 부로 나누어 같은 답변에 이어 씁니다. 자동 생성은 최대 4구간 또는 10분 뒤 일시정지하며 **계속**으로 같은 답변을 이어갑니다. 엔진의 종료 사유가 불명확하면 완료로 단정하지 않고 수동 이어쓰기를 제공합니다. 사용자가 중지한 뒤에는 자동으로 재개하지 않습니다. **전체 복사·파일 저장**은 저장된 모든 구간을 사용합니다. 앱 강제 종료·저장 공간 부족·모델 오류까지 발생하지 않는다는 보장은 아니며, 확인된 중단 이유와 이미 저장된 부분을 남깁니다.

다른 방을 열어도 실행 결과는 원래 방으로 돌아갑니다. 새 요청은 대기열에 넣고 순서 변경·취소할 수 있습니다. 메시지 수정·답변 재생성은 기존 대화 버전을 보존하며 이전 도구를 다시 실행하지 않습니다. 상세 계약은 [긴 답변·다중 채팅](chat-output-and-threads.ko.md), [한 대화에서 계획·목표·스킬 쓰기](work-modes-and-skills.ko.md)를 참고하세요. 이 안내는 현재 소스의 흐름을 설명하며, 실제 설치·실기기 통과 여부는 최신 검증 기록을 확인합니다.

## 필요한 목표와 스킬 사용

일반 작업에는 목표 등록이 필요하지 않습니다. 여러 차례 이어갈 일을 보관하려면 대화에서 지속 목표로 저장할 결과·완료 기준·조건을 요청합니다. 목표를 만드는 것은 초안을 저장하는 일이며, 목표를 시작하거나 일시 정지·재개·해제하는 요청과 구분됩니다. 시작·재개는 **한 번의 제한된 실행**을 대기열에 넣으며 주기 실행이나 무제한 자율 실행을 켜지 않습니다. 새로운 계정·파일 접근 권한도 추가하지 않습니다.

현재 방에 목표가 있으면 **+ → 대화의 목표 보기**에서 초안·완료 기준·상태를 확인하고 직접 수정할 수 있습니다. 기준을 체크하면 사용자의 직접 확인으로 기록되며 실행 기록의 검증과 구분합니다. 목표 저장·대기열 등록·지침 읽기만으로 전체 목표를 완료 처리하지 않습니다. 해제는 별도 확인 후 저장 목표와 연결 실행을 정리하며 이미 만든 외부 파일·일정은 유지합니다.

스킬은 작업에 필요한 지침이며 모델이 `list_skills`·`read_skill`로 찾아 읽습니다. 사용자가 먼저 스킬을 골라야 요청을 처리하는 구조가 아닙니다. **+ → 스킬 찾아보기**는 본문과 지원 도구·한계를 읽는 참고 메뉴이고, 열었다고 요청이 전송되거나 권한이 생기지 않습니다. 스킬을 추가해도 모델 가중치가 재학습되지는 않습니다.

선택적으로 `/plan 요청 내용`, `/review 요청 내용`, `/research 공개 주제`처럼 **이번 요청에만** 범위를 지정할 수 있습니다. `/act`·`/debug`·`/goal`도 다음 메시지의 숨은 모드를 바꾸지 않습니다. 새 일반 입력은 예전 방의 모드 선택에 고정되지 않습니다. 이미 저장된 큐와 이어쓰기는 당시의 `mode`·`allowTools`를 보존하므로 과거 읽기 전용 요청이 쓰기 가능으로 바뀌거나 도구 금지 이어쓰기에 실행 권한이 추가되지 않습니다. 자세한 범위와 목표 전용 7도구는 [계획·목표·스킬 안내](work-modes-and-skills.ko.md)를 참고하세요.

## 이번 기능 사용

- 메뉴 → **문자·일정 분석**에서 전체/올해 문자 분석을 시작합니다. 대화에서도 필요한 분석 목적과 기간을 적어 요청할 수 있습니다. 실제 조회 범위·건수와 처리하지 못한 부분을 구분하며 목록 수만으로 전체 내용 분석을 완료했다고 보지 않습니다.
- 일정 후보의 제목·시작·종료를 확인하고, 원하는 캘린더와 후보를 선택한 뒤 등록합니다. 기본 종료는 시작 1시간 뒤이며 수정할 수 있습니다. 저장 후 실제 일정 ID를 확인하고 재등록 중복을 검사합니다. 저장된 후보는 삭제할 수 있습니다.
- 메뉴 → **이미지 작업실**에서 SDXL 고품질 모델(약2.8GB)을 내려받습니다. 기존 모델이 있으면 **고품질 모델로 교체**를 누릅니다. 다운로드와 파일 검증이 끝나야 새 모델로 바뀝니다. 기본1024×1024/40단계이며, 한국어 장면 설명은 기기에서 정리한 뒤 생성합니다. 통화·다른 앱 사용·발열에 따라 속도를 낮추고 진행 중인 계산은 이어갑니다. 생성 후 **갤러리 저장**을 선택할 수 있습니다. 예전512×512/LCM의 약2분 기록은 새 SDXL의 소요 시간이 아니며, 새 모델의 실제폰 품질·시간 검사는 진행 전입니다.
- 설정의 **내 PC의 계산 자원 → 내 PC 연결**은 같은 공유기의 작업기를 찾고 PC에 표시되는 일회용 코드를 입력하는 흐름입니다. PC 작업기는 처음 한 번 설치·허용해야 합니다. **이미지 · 휴대폰**은 설치한 SDXL, **이미지 · PC 정밀**은 연결한 PC의 FLUX를 사용하며 PC가 응답하지 않으면 휴대폰으로 처리합니다. 작업·대화·완성 파일은 스마트폰에서 관리합니다. PC에는 모델과 실행 프로그램이 남고, 생성 입력·참고 사진·완성 이미지는 앱에서 PC 파일로 저장하지 않는 전달 경로를 사용합니다. **연결 파일 가져오기 · 고급**만 파일 선택기를 엽니다. 실제 LAN 연결과 새 PC 전달 경로의 실기 검증은 별도로 확인합니다.
- 메뉴 → **대화 기록**에서 비서 자체 대화를 검색·내보내기·삭제합니다. 카카오톡 과거 대화는 해당 앱에서 내보낸 텍스트를 **자료 연결·분석**에 가져옵니다.
- 작업 기록의 VERIFIED는 확인된 결과, PREPARED는 외부 작성 화면 또는 요청 준비, FAILED/UNVERIFIED는 결과 확인이 더 필요한 상태입니다. 외부 화면을 연 것만으로 저장·발송 완료라고 표시하지 않습니다.

현재 APK는 기능 통합과 기기 검증 중입니다. 화면이나 작업 흐름은 빌드에 따라 달라질 수 있습니다. 기본 모델 추론과 자료 처리는 기기 안에서 진행하고, 사용자가 연결한 PC의 계산 자원을 선택해서 활용할 수 있습니다. 유료 API 키는 필요하지 않습니다. 모델 파일은 APK에 포함되지 않습니다.

## 시작하기

1. **모델** 화면에서 공식 배포 항목을 내려받거나 직접 파일을 가져옵니다.
2. 가져온 모델은 배포자가 제공한 SHA-256을 확인하고, **벤치마크**를 실행해 이 기기에서 동작하는지 확인합니다.
3. **선택**을 누른 뒤 **대화** 화면으로 돌아옵니다. 한 번에 하나의 모델만 메모리에 올립니다. 자동 선택은 기기에서 실측한 준비 상태를 따릅니다.
4. 대화창에 질문이나 작성 요청을 입력합니다. 이메일 초안, 간단한 텍스트·표·코드 작성은 대화로 요청할 수 있습니다. 실제 발송이나 외부 저장은 별도 확인이 필요합니다.

모델 파일이 없거나 기기에서 성공한 측정이 없으면 일반 모델 추론을 시작할 수 없습니다. 일정 확인, 메모, 일부 승인형 도구는 모델 응답과 별개로 동작할 수 있습니다.

## 자료 연결·분석

대화 화면의 메뉴에서 **자료 연결·분석**을 엽니다.

### 카카오톡 등 대화 내보내기

1. 메신저 앱에서 필요한 대화 파일을 먼저 내보냅니다.
2. **텍스트 파일 선택**을 눌러 TXT, CSV 또는 일반 텍스트를 직접 고릅니다.
3. 가져오기가 끝나면 인식한 메시지 수, 형식, 조각 수를 확인합니다. 인식 결과는 선택한 파일의 범위만 뜻합니다.
4. 목록의 **이 자료 분석**을 눌러 선택 자료를 질문하고, **삭제**를 눌러 해당 가져오기 자료와 저장 조각을 지울 수 있습니다.

앱은 카카오톡 전체 대화나 다른 앱의 비공개 파일을 자동으로 읽지 않습니다. 알림 연동도 권한을 켠 시점 이후에 OS가 제공하는 범위에 한정됩니다.

### 문자와 통화 기록

- **문자 접근 허용**을 누르면 Android 권한 요청이 나타납니다. 허용만으로 읽기가 시작되지는 않습니다. 이후 **문자 가져오기**를 눌렀을 때에만 SMS 제공자 자료를 가져옵니다. 저장 자료는 암호화된 로컬 저장소에 기록되며 이 화면은 문자 본문을 출력하지 않습니다.
- **통화 기록 접근 허용**은 별도 권한입니다. 권한을 허용한 뒤 **통화 기록 요약**을 눌러야 조회됩니다. 결과는 통화 시각 범위·유형·길이 같은 메타데이터이며 통화 녹음이나 통화 내용을 읽거나 전사하지 않습니다.

### 녹음 파일

- **오디오 파일 직접 선택**을 눌러 시스템 파일 선택기에서 분석할 파일을 고릅니다. 이 선택은 광범위한 미디어 권한 없이 가능합니다.
- 녹음 파일 메타데이터 목록이 필요하면 별도로 **오디오 접근 허용** 후 **녹음 메타데이터 조회**를 누릅니다. 이 조회만으로 음성 내용은 열지 않습니다.
- 직접 선택한 녹음은 기기에서 짧은 PCM WAV 조각으로 변환한 뒤 로컬 전사 작업에 전달됩니다. 진행 중 대화 화면 상태에 조각 번호와 시작 시각이 표시됩니다. 완료한 전사 자료를 대상으로 같은 대화에서 질문할 수 있습니다. 표시한 시각은 약15초의 처리 구간 경계이며 단어별 시각이나 화자 식별이 아닙니다.

파일을 고르기 시작한 대화와 자료 접근 범위를 보존합니다. 선택기에서 돌아왔을 때 다른 방을 열었다고 새 방의 자료로 가져오지 않습니다. 원래 범위를 확인할 수 없거나 선택 요청을 복구할 수 없으면 다시 선택하도록 안내합니다. 취소·실패 시 해당 실행이 만든 변경되지 않은 미완성 자료만 정리하며 사용자가 수정한 내용은 임의로 삭제하지 않습니다. 전사·근거 구조의 소스 검사와 실제 기기의 음성 인식 정확도·전체 파일 분석 성공은 별도 검증입니다.

## 기억, 메모, 할 일

**기억과 할 일** 화면에서 장기 기억을 직접 입력하고 저장할 수 있습니다. 앱은 모든 대화를 자동으로 장기 기억으로 바꾸지 않습니다. AI가 제안한 기억은 승인 전까지 사용되지 않습니다. 삭제할 기억은 화면에서 선택해 지웁니다. 메모와 리마인더를 확인하고, 지원되는 권한을 별도로 설정할 수 있습니다.

## 현재 한계

- 모든 메신저 기록, 이메일, 통화 내용, 기기 파일을 한꺼번에 읽는 기능은 없습니다.
- 문서 화면은 구현된 TXT/CSV/PDF 작업에 한정됩니다. DOCX/XLSX 일반 편집, 신뢰 가능한 OCR, 새 장면을 합성하는 동영상 생성의 지원 범위는 개별 도구와 최신 검증 기록을 확인합니다. 이미지 생성은 위 이미지 작업실을 이용합니다.
- 모델의 고정 가중치를 사용자 대화로 계속 재학습하지 않습니다. 지원되는 기억 기능에서 승인한 내용만 기억으로 보관할 수 있습니다.
- 단말 성능과 전력 사용은 모델·설정·기기 상태에 따라 달라집니다. 안내된 벤치마크는 특정 Galaxy S26에서 얻은 결과이며 다른 기기의 보장이 아닙니다.

## 인터넷 없이 사용하기

모델을 한 번 내려받은 뒤 기본 대화와 기기 내 자료 처리는 인터넷 없이 가능합니다. 개발 검증에서는 INTERNET 권한을 제거한 전용 APK에서 E2B 응답과 암호화 메모 저장·검색·삭제를 통과했습니다. 평상시 설치본은 모델 다운로드와 검증된 업데이트를 위해 네트워크 권한을 유지합니다.

## 자동 업데이트

현재 릴리스0.1.2는 앱이 GitHub의 서명된 패키지를 확인해1000→1002로 스스로 업데이트하는 검증을 통과했습니다. 동일 범위의 업데이트는 자동 적용하며, 새로운 권한·기능 범위가 생기면 변경 내용을 확인합니다. Android가 별도의 설치 확인을 요구하는 경우에는 앱의 설치 알림을 이용합니다. 실제 업데이트 후 인증서와 반복 작업 승인4개의 유지도 확인했습니다.

## 채팅방·프로젝트와 긴 답변

왼쪽 목록에서 새 채팅과 프로젝트를 만들고 방 이름 변경, 검색, 고정, 보관·복원, 이동, 복제, 내보내기와 삭제를 사용할 수 있습니다. 방을 옮겨도 초안·첨부·모델·깊게 생각·읽던 위치를 따로 복원합니다. 메시지 수정·재생성은 기존 내용을 지우지 않고 분기로 보존합니다.

진행 중인 작업은 원래 방에 남고 새 요청은 대기열로 들어갑니다. 긴 답변은 구간별로 저장하며, 생성 한도나 자원 문제로 쉬는 경우 저장된 내용 아래에 상태와 **계속** 버튼을 표시합니다. 사용자가 중단한 요청을 자동으로 다시 시작하지 않습니다. 답변의 복사·파일 저장은 화면에 보이는 일부 문단이 아닌 저장된 전체 본문을 사용합니다.

## 작업 과정 확인

답변 앞의 작업 카드를 열면 요청 준비, 계획 요약, 실제 도구 시도, 승인, 결과 검증과 파일 변경 근거를 시간순으로 볼 수 있습니다. 오래된 항목은 추가로 불러옵니다. **응답 종료**는 답변 생성이 끝났다는 뜻이며 모든 외부 작업이 성공했다는 뜻은 아닙니다. 검증되지 않았거나 중단된 작업은 그 상태로 표시합니다.

## 설정과 파일 저장

- 모델 화면의 **이 대화에서 사용**과 **깊게 생각**은 현재 방에 저장됩니다. CPU/GPU와4K/8K 선택은 별도의 벤치마크 옵션입니다.
- 프로젝트에서 개인 기억 참고와 기억 후보 생성 여부를 따로 선택합니다. 변경한 정책은 기존 방에도 반영하며 기존 승인 기억을 임의로 지우거나 다른 프로젝트로 옮기지 않습니다.
- 문서·대화·MP4 저장은 저장 버튼을 누른 시점의 복사본으로 진행합니다. 파일 선택기에서 돌아와도 다른 문서로 바뀌지 않습니다. 앱 프로세스가 종료되어 요청을 복구할 수 없으면 빈 파일을 쓰지 않고 다시 저장하도록 알립니다.
- 설정에서 앱·Google 계정 연결, 선택적인 PC 연결, 확장 파일 보안 검사에 들어갈 수 있습니다. 확장 검사는 ZIP·분리 manifest와 독립적으로 확인한 SHA/commit이 필요합니다. 임의 실행 코드나 실행형MCP를 설치하는 메뉴는 아닙니다.
- 프로젝트 파일 수정은 실제로 읽은 전체 원문과 원본 SHA가 확인되어야 합니다. 일부 발췌만 읽은 파일이나 다른 방·프로젝트의 읽기 기록으로 전체 파일을 덮어쓰지 않습니다. 문맥 예산을 넘으면 자료를 줄여 읽은 척하지 않고 이유를 표시합니다.
