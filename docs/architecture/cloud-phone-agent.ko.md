# 클라우드 에이전트의 휴대폰 도구 연결

2026-11-15. 구현과 검증 단계는 PROJECT_STATE.md와 agent-change-log.md를 기준으로 본다. 기본 로컬 추론과 별도로 사용자가 선택하는 경로다. 새 유료 API 키를 요구하지 않고 개인 PC의 기존 Codex CLI 로그인으로 실행한다.

## 실행 구조

일반 대화 → 새 요청의 외부 전달 권한 캡처 → 인증서 pin/페어링을 유지한 개인 PC 브로커 → 별도 Codex 하위 실행 → 범위가 고정된 MCP 도구 → 휴대폰 부모의 실제 실행/승인 → 실제 결과 반환 순서다. 모델의 설명이나 종료 응답은 실행 영수증이 아니다.

휴대폰이 요청·대화·프로젝트·승인·취소 권한을 유지한다. 클라우드 모델은 도구를 선택하고 결과를 보고 다음 행동을 결정한다. 호스트는 실제 등록 도구/인자/프로젝트/권한/순서/중복/효과/후속 조회를 검사한다. 문서·메모·도구 본문은 새로운 사용자 명령이나 실행 권한이 아니다.

1086의 첫 실제 시험은 별도 합성 프로젝트에서 PC 폴더 검사/파일 읽기와 휴대폰 시각/프로젝트 저장소 검사를 실행한 읽기 전용 연결이다. 일반 대화의 쓰기 성공으로 확대하지 않는다.

## 일반 대화의 첫 지원 범위

모델 선택기의 `클라우드 · 휴대폰 도구`를 선택하고 요청/허용 도구 결과의 외부 전달에 동의한 뒤 새 요청을 보낸다. 모델 설정에서 연결을 해제하면 이미 캡처된 권한도 만료된다. 다른 로컬 모델을 계속 선택할 수 있다.

첫 `phone-only` 세션은 `get_current_datetime`, `inspect_project_storage`, `save_note`, `search_notes`, `read_note` 중 현재 프로젝트에서 허용한 도구만 제공한다. PC 폴더 접근을 자동으로 얻지 않는다. 메모 수정의 기존 모델 입력/원문/부분 수정/승인 검증을 우회하지 않으며 `patch_note`는 이 경로에서 제공하지 않는다. 첨부, 저장 목표 연결, 기존 실행의 재개/추가 지시, 그 밖의 전화/문자/메일/화면 조작은 이 경로의 검증 범위 밖이다.

모델의 일시적 계획 `plan_task`는 현재 세션의 제공 도구 중 필요한 부분만 선택한다. 휴대폰이 요청과 권한을 확인하고 계획/후속 조회 조건을 암호화된 실행 문맥에 저장한 다음 수락한다. 이는 영속 GoalStore 목표나 변경 승인, 실행 완료가 아니다. 메모 저장에는 후속 검색이 함께 선택돼야 한다. 실제 쓰기는 기존 PendingAction과 runTool을 통과하며 승인 대기 후 외부 권한을 다시 확인한다.

완료는 모델의 `reported_done`과 별개로 실제 휴대폰 콜백/실행 원장, 같은 대상의 후속 조회, 브로커의 미해결 호출, 부모 실행의 상태를 대조한 뒤 판단한다. 실패·미확인·PREPARED·누락은 일시 정지하며 서버가 보내는 휴대폰 결과를 로컬 실행 증거로 가져오지 않는다. 모델 답변만 있는 경우 도구 실행 없이 생성했다는 표시를 붙인다.

## 개인 PC 운영

브로커와 provider 설정은 저장소 밖의 기존 개인별 비공개 Compute 디렉터리에 둔다. `agent-provider.json`은 실행 파일/전체 SHA, Python, MCP 스크립트/전체 SHA, 정적 임시 파일 디렉터리, 비어 있는 실행 디렉터리와 선택적 모델 이름을 고정한다. 원 요청이나 서버 capability를 명령행·평문 설정·로그에 저장하지 않는다. 기존 페어링 토큰과 인증서/DPAPI 경계를 재사용한다.

원격 휴대폰은 phone capability로 자기 세션의 실행 시작/상태/중지를 요청한다. 서버 내부에서만 agent capability를 하위 프로세스 환경으로 전달한다. MCP에는 등록/승인/결과 제출/세션 부트스트랩 권한이 없다. 별도 loopback 부트스트랩은 인증된 호스트 IPC이며 모델/일반 원격 인터페이스가 아니다.

현재는 한 번에 클라우드 하위 실행 하나, 세션당 도구 호출 최대18회, 모델 실행 최대300초다. 로컬 브로커의 개인 데이터는 제한된 RAM과 암호화된 휴대폰 기록으로 다룬다. 클라우드 사업자의 원격 보존 정책을 이 앱의 RAM 제한으로 설명하지 않으며 원격 보존은 이 시험에서 검증하지 않았다. 브로커/하위 실행 원장은 RAM 전용이며 재시작하면 세션을 폐기한다. 누적 세션64개 한도, PC 독립 부모/동일 작업의 PC UI/영속 복구 원장/배경 무인 실행은 후속 과제다. 재시작·응답 단절로 효과가 불명확한 쓰기를 자동 재등록/재실행하지 않는다.

새 실행 파일·MCP 스크립트로 바꾸면 운영자가 검증한 SHA 설정도 갱신해야 한다. 개인 PC/폰 권한과 실제 자료의 외부 전달 동의는 별개다. 현재 앱의 특정 합성 시험 결과는 전체 스마트폰 업무나 상용화 완료를 뜻하지 않는다.
