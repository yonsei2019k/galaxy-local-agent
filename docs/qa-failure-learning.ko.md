# 실패 진단과 교훈 재사용

1. 시험 결과를 성공, 실패, 보류, 미실행으로 남긴다. 실패에는 버전, 실행 단계, 고정 오류 코드, 마지막 확인 상태, 도구 효과 유무를 기록한다. 실패 원인이 분명하지 않으면 원래 기록을 보존하고 다음 반복에서 누락된 단계 경계를 추가 계측한다.
2. 작업 방식의 문제는 입력의 핵심 조건, 피해야 할 행동, 대체 경로, 완료 확인 방법을 짧은 교훈으로 만든다. 다음 같은 종류의 합성 과제에서 교훈 적용 전후를 비교한다. 검증 전 교훈은 제안으로만 유지한다. 실행기에는 내부 추론 원문 대신 선택한 도구·관찰·이탈 조건을 기록한다.
3. 코드·권한·저장·통신 문제는 에이전트가 앱이나 권한을 변경하지 않고 개발 검토 대상으로 남긴다. 같은 입력의 회귀 시험과 인접 안전 경계 시험을 거친 뒤 배포 후보에 묶는다. 효과가 불명확한 쓰기는 재시도하지 않고 대상 상태부터 확인한다.
4. 로그에는 대화 원문, 인증 값, 주소, 계정 식별자, 결제 입력, 사진을 넣지 않는다. APK 설치, 실제 폰, 모델, 합성 시험 결과는 각각 별도 증거로 남긴다.

기능 시험은 이전 통과 기록을 활용한다. 실패했던 시나리오, 아직 확인하지 않은 복합 흐름, 변경된 화면이나 공통 실행 경로에 직접 영향을 받는 흐름부터 실행한다. 시험 기록에 선정 이유와 기존 결과를 남기고, APK 빌드에 필요한 자동 검사 결과는 실제 기능 시험과 따로 기록한다.

합성 과제는 `py -3 pc-worker/eval/goal_only_simulation.py --require-complete --out .local/qa-<실행ID>`로 실행해 각 시도의 증거와 판정 결과를 남긴다. 같은 실패를 비교할 때는 새 실행 ID를 사용한다. 개별 시도에서 실행기 예외가 발생하면 해당 시도 ID와 예외 유형을 기록하고 나머지 시도를 계속 평가한다. 실행기는 전체 보고서를 저장한 뒤 실패 코드로 종료한다. Android CI는 합성 판정 파일이 생성되면 합격 여부와 관계없이 `synthetic-scenario-report`에 7일간 보관한다. 실기기 로그는 이 아티팩트에 포함하지 않는다.

기존 로컬 계획기의 `PlanningFeedbackStore`는 이미 도구 실패와 검증 상태를 집계해 반복 호출 회피, 대체 경로 탐색, 완료 전 확인 힌트를 다음 계획에 제공한다. 새로 발견한 교훈은 이 저장소의 분류 코드를 재사용하고, 현재는 사용자 승인 뒤에 승인된 교훈으로 표시한다. 원격 시험 로그에서 교훈을 자동 추출·검증해 승격하는 연결은 남아 있다.

PC 연결 문제는 `cloud_bridge_retry`와 `cloud_bridge_stop`을 함께 확인한다. 전자는 재시도를 예약한 고정 작업 코드와 다음 시도 번호를, 후자는 최종 중단 직전의 세션 상태와 마지막으로 관찰한 모델 실행 상태를 기록한다. 상태 조회 시간 초과에는 같은 연결에서 한 번 조회를 반복하고, 모델 작업 시작은 PC가 명시적으로 시작을 거부한 `PROVIDER_BUSY` 응답에 한해 기존 권한 검사 후 재시도한다. 시간 초과가 난 도구 실행 요청은 재전송하지 않는다.

## 개발·검증 도구

- [Android UI Automator](https://developer.android.com/training/testing/other-components/ui-automator)는 앱 밖에서 시스템 화면까지 검증하는 개발용 후보. 자체 앱·합성 시험기의 결제 직전 중단과 앱 전환 시험에 한정한다. 앱 내부 UI는 기존 Android instrumentation과 React 테스트부터 재사용한다.
- [Appium MCP와 UiAutomator2](https://appium.io/docs/en/latest/ecosystem/tools/)는 개발 환경의 시험 후보. 운영 휴대폰 에이전트에 범용 화면 권한을 부여하지 않으며, 앱·기기·도구 범위를 제한한 시험 구성을 검증한 뒤 연결한다.
- [Playwright Android](https://playwright.dev/docs/api/class-android)는 ADB가 필요한 실험적 Chrome/WebView 지원이다. 무선 디버깅 없는 일상 운영 경로에는 적용하지 않는다.
