# 통화 후속 비서와 정확도 검증

상태: 2026-10-31 서명1018 설치와 실제 삼성 통화 녹음 폴더 연결을 확인했다. 선택한 실제 녹음의 전사 두 구간은 완료·보존됐으나, 첫 후속 정리 단계가330초 한도에 걸려 중단됐다. 일정·메일은 실행되지 않았다. 현재 단계별 계측과 성능 조정을 진행 중이며 실제 후속 보고서 완료·한국어 통화 정확도 검증은 아직 통과하지 않았다. 구현된 코드나 합성 단위 검사만으로 실제 통화 정확도가 확보됐다고 말하지 않는다.

## 사용 흐름

한 번만 설정·참고 → 자동화 → 통화 후속 비서에서 삼성 전화가 사용하는 통화 녹음 폴더를 연결하고 통화 종료·알림 권한을 확인한다. 연결한 시점 이후의 새 파일만 대상이며 예전 녹음·다른 폴더를 자동으로 읽지 않는다. 삼성 전화의 자동 녹음 설정 자체를 변경하거나 통화를 직접 녹음하지 않는다.

통화가 끝나면 파일 크기와 수정 상태가 최소30초 동안 안정되고 실제 끝까지 읽을 수 있는지 확인한다. 새 파일의 전체 해시와 실제 전사 입력 사본의 해시를 대조한 후 영속 큐에 넣는다. 앱이 강제 종료되거나 작업이 중단돼도 확인된 전사·분석 구간을 보존한다. 다른 사용자 작업과 새 통화를 우선하고, 배터리·절전·발열 상태가 안정되면 이어간다. Android의 예약 지연과 모델 처리 시간 때문에 즉시 완료를 보장하지 않는다.

결과는 비공개 ‘통화 후속’ 프로젝트의 해당 통화 대화에 저장된다. 원음 구간·인용·확인할 이름/날짜/수신자와 일정·메모·메일 후속 후보를 표시한다. 알림을 누르면 그 대화로 돌아간다. 진행 중에는 전사와 근거 분석 구간 수를 대화에서 확인할 수 있다. 설정에서는 중지·이어 분석, 녹음 열기, 페이지별 전사 원문 확인을 제공한다.

보고서는 자동 정리 기록이다. 실제 일정 등록과 메일 발송은 별도 도구와 해당 건의 확인을 거친다. 보고서의 날짜·이름·수신자를 고치거나 필요한 작업을 같은 대화에서 요청한다. 녹음 속 발언은 사용자의 도구 승인으로 쓰지 않는다. 임상 발언은 원문 검토 자료로 남기며 새로운 처방·판단·수행 지시로 변환하지 않는다.

‘이 녹음의 분석 기록 삭제’는 자동 분석을 중지하고 해당 전사·분석과 수정하지 않은 자동 보고서를 지운다. 직접 수정한 보고서와 삼성 전화의 원본 녹음은 유지한다. 일반 대화를 비우거나 삭제한 뒤 늦은 결과가 다시 게시되지 않도록 별도 경계를 둔다.

## 현재 적용한 정확도·안정성 개선

- 원음과 자동 전사 원문은 변경하지 않는다. 제안과 정정을 원문 위에 덮어쓰지 않는다. 실제 사본의 해시·구간·모델 버전을 저장하고 임시 사본은 작업 종료와 다음 시작 시 정리한다.
- 앞 구간 전체와 현재 구간 전체를 함께 분석한다. 이전 후보 목록의 의미와 중요 값을 유지하고 중복 해시 등 실행용 메타데이터는 모델 입력에서 제외한다. 원문을 조용히 잘라 문맥을 맞추지 않는다. 실제 예산이 부족하면 미완료 상태로 보존한다.
- 모델은 의미와 정확한 인용문을 제안한다. 앱이 실제 전달된 원문에서 유일하게 일치하는 인용의 바이트 위치·해시·오디오 조각 범위를 계산한다. 모델에게 긴 해시를 복사하거나 한글 바이트 수를 계산시키지 않는다. 바뀐 인용·모호한 반복·미전달 자료·잘린 JSON은 거부한다.
- 질문·부정·조건·취소·뒤의 정정을 약속과 구분해 보존한다. 중요한 날짜·시각·이름·금액·기한·수신자는 원음 확인 대상으로 표시한다. 파일 수정 날짜를 실제 통화 시각으로 쓰지 않으며, 확인할 수 없는 상대 날짜는 미확인 상태로 남긴다.
- 현재 ASR가 제공하지 않는 확신도·화자 신원·단어별 시각을 만들지 않는다. 15초 조각의 범위는 단어별 시각이 아니다. 침묵·출력 한도·길이 불일치·미처리 구간은 확인 대상으로 남긴다.
- 전사·모델 처리는5분30초 이하의 협력적 구간으로 나눈다. 각 엔진을 해제한 후 다음 엔진을 로드한다. 네이티브 취소 지연이 있는 경우에도 겹쳐 로드하지 않으며 정확한 벽시계 제한을 보장한 것으로 표시하지 않는다.
- 중지 후 재개, 원본·권한 변경, 삭제와 게시의 경합, 원음 사본 정리, 읽은 내용과 저장한 내용의 일치를 별도 검사한다.

## 모델 선택과 측정 전략

자동 통화 분석은 준비된 Qwen3-ASR1.7B 또는0.6B를 사용한다. 전역 음성 인식 선택은 바꾸지 않으며 사용 가능한 기존 Qwen 선택을 우선한다. 둘 다 없으면 모델 준비가 필요한 상태로 남기고 자동 다운로드하지 않는다.1.7B 기본 후보는 기존 구성의 기준선이며 실제 한국어 통화 정확도 우승 모델로 확정한 것이 아니다. Qwen은 공개 가중치 경로다. [Qwen 공식 저장소](https://github.com/QwenLM/Qwen3-ASR)

ML Kit Advanced 한국어는 앱 화면을 연 상태의 추가 비교 후보다. 공식 GenAI 문서는 앱이 전경에 없으면 포그라운드 서비스를 포함해 실행이 차단될 수 있다고 설명하므로 자동 백그라운드 분석의 필수 경로로 쓰지 않는다. 공식 기기 지원 목록과 이 휴대전화의 실제 준비 상태도 구분한다. [ML Kit 음성 API](https://developers.google.com/ml-kit/genai/speech-recognition/android), [백그라운드 실행 제한](https://developers.google.com/ml-kit/genai)

먼저 동일한 비개인 한국어 합성 음원을 준비된 엔진에 순서대로 입력해 CER/WER, 날짜·시각·이름·부정·정정의 중요어, 처리 시간/원음 길이, 메모리·발열을 기록한다. 이 합성 검사는 기초 동작 검사이며 실제 통화 정확도 점수와 구분한다. 시스템 관리 모델의 가중치 해시를 추측하지 않는다.

다음으로 사람이 원음을 듣고 정답을 확정한 독립 모의 통화 최소40개를 준비하는 것이 목표다. 아직 확보·측정한 수량이 아니다. 간호 행정 용어, 유사 이름, 빠른 발화, 겹말·침묵, 전화 협대역, 잡음,15초 경계를 가르는 부정·날짜를 나누어 평가한다. 교정과 시험 자료를 분리하고 평균 문자 오류율 외에 다음을 따로 비교한다.

| 평가 | 선택·배포 기준 |
| --- | --- |
| 이름·날짜·시각·수신자 오류 | 중요 정보 오류가 적은 후보를 우선하며 미확인은 채우지 않음 |
| 부정·취소·정정·조건 반전 | 회귀 자료에서 잘못된 확정 조치가 있으면 자동 확정 경로로 채택하지 않음 |
| 전사 경계 누락·중복·무음 환각 | 원문 보존, 누락 표시, 고의 반복과 오류 중복 구분 |
| 후속 후보 정밀도·재현율 | 인용 일치와 실제 의도 정답을 따로 채점 |
| 시간·발열·메모리 | 정확도와 함께 측정해 기기에서 지속 가능한 후보 선택 |

현재 자동 다중 ASR 합의, VAD·겹침 구간 통합, 단어 정렬·화자 분리, 사용자 용어의 ASR 직접 주입은 구현·검증됐다고 주장하지 않는다. 우선 같은 원음의 비교 결과를 얻고, 오류가 많은 구간을 두 번째 엔진으로 다시 확인하는 실험부터 추가한다. 불일치 시 다수결로 사실을 정하지 않고 원음 확인으로 넘긴다. 승인한 표기·용어·교정은 별도 버전으로 축적하며 모델 가중치를 휴대전화에서 계속 재학습하지 않는다.

평가 실행 방법과 점수 계산기는 [기기 계측 안내](testing/call-asr/DEVICE-PROBE.ko.md), [평가 계약](testing/call-asr/EVALUATION-CONTRACT.ko.md)에 있다. 실제 개인·환자·업무 녹음과 전사 원문은 Git·외부 검색·공통 로그로 내보내지 않는다.

## Gmail 실제 답장

Gmail의 기존 연결과 허용 범위를 확인하고 실제 계정·원문 메일에서 수신자·제목·대화·답장 헤더를 얻는다. 수신자와 본문 전체를 검토한 한 건만 전송한다. 전송 전에 고정된 요청과 작성 시각을 영속 저장하고, 결과가 불명확하면 자동 재전송하지 않는다. 실제 SENT 상태·메일 내용·답장 헤더를 재조회한 경우에만 발송 확인으로 표시한다. 이는 상대방의 수신·읽음 확인이 아니다. Naver와 회사 메일은 이 경로로 연결됐다고 표시하지 않는다. [Gmail 발송](https://developers.google.com/workspace/gmail/api/guides/sending), [답장 대화 조건](https://developers.google.com/workspace/gmail/api/guides/threads)
