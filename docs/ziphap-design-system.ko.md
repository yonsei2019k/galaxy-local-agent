# ZipHap 디자인 시스템 — "Porcelain & Clasp"

담당: Claude (Codex 할당 X-005). 구현 위치는 `web-ui/src/styles.css`(토큰과 컴포넌트), `web-ui/public/brand/`(브랜드 자산)이다.
적용한 스킬은 `artifact-design`이다. 이 환경에 전용 frontend 디자인 스킬은 없어서, 그 스킬의 기본 원칙을 앱 UI에 적용했다:
- 토큰 기반 라이트·다크
- 의도한 중성색
- 상태를 형태로 인코딩
- 범용 AI 룩 회피

## 1. 콘셉트
ZipHap(집합)의 마스코트는 아이보리 두 조각이 코발트 잠금쇠(clasp) 하나로 묶인 모습이다. 화면도 같은 원리를 따른다.
- **바탕:** 바탕과 카드는 도자기 같은 아이보리다(warm cream이 아니라, 살짝 차가운 porcelain).
- **글자:** 글자는 마스코트 눈의 잉크 네이비다.
- **코발트:** 코발트는 "지금 누를 수 있는 단 하나"에만 쓴다. 새 대화, 보내기, 선택된 모델 표시가 여기에 해당한다. 장식 그라디언트는 쓰지 않는다.
- **볼터치 살구색:** 볼터치 살구색은 "소유자가 해야 할 일"(승인 필요)에만 쓴다.

## 2. 색 토큰
모두 `.workspace`에 있다. 다크는 `.workspace[data-theme="dark"]`에서 같은 이름으로 다시 정의한다. App.tsx가 시스템 설정까지 반영해 `data-theme`을 정한다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--porcelain` / `--canvas` | #F6F5F1 | #121420 | 페이지 바탕 |
| `--surface` | #FFFEFB | #1A1D2B | 카드, 입력창 |
| `--surface-soft` | #F1EFE9 | #212536 | 근거 행, 첨부 칩 |
| `--ink` | #1A1E33 | #ECEAE3 | 본문 |
| `--secondary` / `--muted` | #454B63 / #61677F | #B7BACA / #8E93A8 | 보조, 설명 |
| `--clasp` / `--accent` | #2546D6 | #8198FF | 단일 행동색 |
| `--accent-soft` | #E5EAFC | #1D2550 | 사용자 말풍선, 진행 타일 |
| `--line` / `--line-strong` | #E2DFD6 / #8E8A80 | #2C3044 / #6B7088 | 구분선 / 입력 테두리 |
| `--review`(+soft, ring) | #8F4318, #FBE9DE, #C8693E | #F3B08C, #3A2418, #F3A983 | 승인 필요 |

**대비 실측(WCAG):**
- 본문·보조·상태 글자는 양쪽 테마 모두 4.5:1 이상이다(본문 약 15:1, 보조 최저 4.86:1).
- 입력 테두리와 승인 링은 3:1 이상이다.
- 발신자 색과 상태 색은 분리했다. 이전에는 Claude 이름이 "승인 필요" 색을 같이 써서 상태 의미와 섞였다.

## 3. 타이포
- **글꼴:** 원격 폰트를 쓰지 않는다(오프라인, CSP). 다음 순서의 한국어 우선 시스템 스택을 쓴다. Pretendard(설치돼 있으면) → Apple SD Gothic Neo → Noto Sans KR → Malgun Gothic → system-ui.
- **크기 단계:**
  - caption 11.5
  - small 13
  - body 15(줄 간격 1.7)
  - title 17–18
  - welcome clamp(26–40)
- **조판:** 한국어 문장은 `word-break: keep-all`, 제목은 `text-wrap: balance`, 시각 표시는 `tabular-nums`를 쓴다.

## 4. 형태 규칙
- **알약(capsule, 반경 999):** 코발트 행동 버튼(보내기, 새 대화)이다. 위쪽에 얇은 하이라이트가 있는 clasp bead 모양이다. 추가 지시·중단·모델 선택·첨부 칩도 같은 알약이지만 채우지 않는다.
- **반경:**
  - 카드 16
  - 컨트롤 12
  - 말풍선은 보낸 쪽 모서리만 5
- **선택된 대화:** 코발트 배경 대신 표면색 위에 얇은 테두리를 두고 아이콘만 코발트로 칠한다. 사이드바에서 "들어 올려진 종이"처럼 보이게 하는 것이다.
- **터치 영역:** 모든 터치 대상은 44px 이상이다. 작게 그린 아이콘은 `::after`로 44px 영역을 유지한다.

## 5. 작업 상태 표현 (가짜 상태 금지)
색만으로 구분하지 않는다. 타일 모양, 라벨, 색을 함께 쓴다. 각 상태는 host가 준 phase에서만 나온다.

| phase(tone) | 타일 | 의미 |
|---|---|---|
| running(active) | 연한 코발트 타일과 돌아가는 링(움직임 줄이기 설정이면 정지된 링) | host가 "running"이라고 보고한 동안만 |
| approval·waiting_approval·paused(review) | 살구 타일과 바깥 열린 링, 카드 테두리도 살구색 | 소유자 행동 필요 |
| completed(complete) | 채운 초록 타일 | 응답 종료. 외부 효과 완료와는 별개다 |
| failed(failed) | 채운 빨강 타일 | 실패 |
| queued·cancelled·interrupted 등(neutral) | 테두리만 있는 타일 | 대기·중단 |

**근거(receipt) 행:** 테두리가 있는 작은 표처럼 보여 준다. 라벨 다음에 host 문구가 온다.

## 6. 협업방
- **소유자 메시지:** 오른쪽, 연한 코발트 말풍선이다.
- **에이전트 메시지:** 왼쪽, 흰 카드다. 이름 앞에 발신자 색 점(bead)을 둔다. Codex는 코발트, Claude는 살구 갈색이다.
- **정책 줄:** 협업 메시지는 정보일 뿐 실행 권한이 아니다. 이 정책 줄은 입력창 위에 항상 보인다.

## 7. 레이아웃·접근성
- **화면 폭:** 393px(휴대폰) 기본, 940px부터 사이드바를 고정(252px), 1400px까지 본문 폭은 760px로 제한한다.
- **포커스와 모션:** 포커스는 2px 코발트 외곽선이다. `prefers-reduced-motion`이면 회전을 끈다. `forced-colors`에서는 시스템 색과 테두리를 쓴다.
- **안전 영역:** 기존 safe-area inset 처리와 `[hidden]` 규칙을 유지한다.

## 8. 자산
- **`web-ui/public/brand/ziphap-clasp-mark.svg`:** 마스코트의 두 머리 조각과 코발트 bead로 만든 단순 마크다(48×48). 원본 마스코트 PNG는 수정하지 않았다.
- **BrandMark 교체 제안:** `Conversation.tsx`의 BrandMark를 이 마크로 바꾸는 것은 기능 파일 변경이라 root가 판단한다.

## 9. 검증 범위
- 정적 하네스(실제 TSX와 같은 마크업·클래스)로 393px/1400px, 라이트/다크를 확인했다.
- 실제 앱 WebView 렌더링과 폰 실기는 미검증이다. root가 0.1.18의 흰 화면 결함을 수정하는 중이다.
